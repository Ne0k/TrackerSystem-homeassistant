# Brand assets for home-assistant/brands

The icon shown by HACS and Home Assistant does **not** come from this repository —
it is served from the central [home-assistant/brands](https://github.com/home-assistant/brands)
project. This folder holds the ready-made assets for that submission.

## How to submit (one time, via the GitHub website)

1. Fork [home-assistant/brands](https://github.com/home-assistant/brands).
2. In your fork, create the folder `custom_integrations/trackersystem/`.
3. Upload the four PNG files from this folder
   (`icon.png`, `icon@2x.png`, `logo.png`, `logo@2x.png`).
4. Open a pull request titled: `Add trackersystem (custom integration)`.

After the PR is merged the icon appears automatically at
`https://brands.home-assistant.io/trackersystem/icon.png` and in HACS/HA.
